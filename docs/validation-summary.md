`verify`는 외부 AI와 웹 검색을 호출하지 않는 자동 회귀 검사입니다. 음성 입력·읽어주기는 브라우저 API mock으로 오류·취소·복구 흐름을 검사합니다. 실제 행사 기기의 마이크 인식률, 한국어 발음, 스피커 출력, NVDA·VoiceOver 사용성은 이 결과에 포함되지 않습니다. 실제 사용자 대상 사용성 평가는 후속 과제입니다.

지원 범위는 구조화된 대표 생활정보 안내, 목적 확인, 제한적 공식 검색과 공식 확인 경로 제공까지입니다. 공식 행정 처리, 개인정보 조회, 진단, 수급 자격 확정, 실제 신청 대행, 정확한 길찾기는 지원하지 않습니다. 음식물쓰레기·온라인 전입신고·금연상담 비용 등 일부 질문은 공식 확인 경로 중심의 부분 안내입니다.

외부 검색에는 공유 한도와 동시 요청 제어를 적용해 API 비용과 과도한 호출을 방지합니다. 한도 도달 또는 외부 저장소 장애 시에도 구조화된 주요 안내는 계속 이용할 수 있습니다.
