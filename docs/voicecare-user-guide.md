# VoiceCare 이용 안내

기본 지역은 성남시입니다. [서비스 열기](https://seongnam-voicecare-ai.vercel.app/) · [검증 범위와 한계](validation-summary.md)

성남시가 직접 운영하는 공식 서비스가 아닙니다. 개인의 자격을 확정하거나 실제 신청을 대신하지 않습니다.

1. **음성으로 질문하기**로 질문합니다. 인식한 문장을 확인하고 필요하면 글자로 고친 뒤 **이대로 질문하기**를 누릅니다. 인식만으로 질문을 자동 전송하지 않습니다.
2. 음성을 쓸 수 없거나 원하지 않으면 홈과 재질문 영역의 **글자로 질문하기** 입력란과 **질문하기** 버튼을 사용합니다. 휴대폰 키보드의 음성 입력도 선택할 수 있습니다.
3. 제도명을 모르면 입력란 아래의 **☰ 생활정보 찾기**를 고르고 필요한 항목을 누릅니다. 바로 안내하므로 위로 돌아가 전송 버튼을 찾을 필요가 없습니다. 복지·이동·교통·건강·민원·생활·기타는 메뉴 안에서만 표시합니다. 메뉴는 두 단계이며 닫기·배경 클릭·Escape로 닫고, 키보드 포커스는 메뉴 안에서 순환합니다.
4. 확인 질문이 나오면 원하는 도움을 선택합니다. ‘이동수단 알려줘’에는 일반 교통·차량·비용 도움을 구분하는 선택이 나옵니다. **잘 모르겠어요** 또는 **새 질문하기**로 다시 시작할 수 있습니다.
5. 핵심 안내를 읽고 **준비물은?**, **요금은?**, **전화번호는?** 등 후속 질문을 선택합니다. 별도 서비스명을 반복하지 않아도 직전 서비스에 이어서 묻습니다. 다른 서비스를 명시하면 새 주제로 처리합니다.
6. 전화·공식 안내 버튼과 다음 행동을 확인합니다. 긴 대상·서류·진행 순서는 **자세히 보기**로 펼칩니다. 전화 링크는 사용자가 눌러야 동작하며 자동으로 전화하지 않습니다. **미확인**은 자료에 없는 내용이나 현재 운영 여부를 확정하지 못했다는 뜻입니다.
7. 답변 아래의 **🎤 다시 음성으로 질문하기**를 한 번 누르면 그 자리에서 인식을 시작합니다. **글자로 다시 질문**은 같은 위치의 입력란으로 초점을 옮깁니다. **처음으로**는 현재 질문·답변·확인 문맥을 모두 지우고 홈의 음성 버튼으로 돌아갑니다.

**답변 듣기**는 핵심 안내와 다음 행동·확인 제한을 읽습니다. **상세 안내 전체 듣기**는 대상·서류·절차·문의 등 화면의 상세 안내도 읽습니다. 자동 재생하지 않으며, 중지·새 질문·입력 수정은 이전 읽기를 취소합니다. 실제 음성 지원과 발음은 브라우저·기기에 따라 다릅니다.

음성 버튼에 **듣고 있어요…**가 표시되면 질문을 말합니다. 인식 중에는 같은 버튼을 눌러 취소할 수 있습니다. 종료 후에는 문장을 확인하고 **이대로 질문하기**를 눌러 보냅니다. 브라우저 확정 결과도 오인식할 수 있으므로 자동 제출은 하지 않습니다. 마이크 권한 거부, 무음, 네트워크 오류, 미지원 브라우저에서는 안내를 확인하고 글자로 질문할 수 있습니다. 실패하면 **다시 말하기** 또는 **글자로 질문하기**를 누릅니다. 30초가 지나거나 무음·미확정 결과만 있거나 문장이 지나치게 짧으면 전송하지 않습니다. 인식 문장이 너무 길면 자르지 않고 수정하도록 안내합니다.

외부 검색이 불가능하면 그 사유와 공식 확인 경로를 표시합니다. 공유 한도가 끝났을 때 반복 재시도를 유도하지 않으며, 검토된 내부 안내와 생활정보 메뉴는 계속 이용할 수 있습니다. 검색 실패나 링크 제시를 상세 답변 검증 완료로 보지 마세요.

이름·주민등록번호·개인 전화번호·상세 주소·개인 질환 정보를 입력하지 마세요. 자동 가림은 완전하지 않습니다. 질문은 외부 AI 검색으로, 음성은 브라우저 제공자의 음성 서비스로 처리될 수 있습니다. 앱은 질문·음성 원본을 DB에 저장하지 않습니다.
