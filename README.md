# Seongnam VoiceCare AI · Astra

성남 공공·생활정보를 글과 음성으로 찾는 경진대회 프로토타입입니다. **성남시가 운영하는 공식 서비스가 아닙니다.**

## 현재 상태

2026-09-07 개편 작업본입니다. 공개 Production은 종전 버전이며 이 개편은 아직 배포하지 않았습니다. 사용자의 요청에 따라 추가 유료 평가를 중단하고 오프라인 검증만 수행했습니다. 20개 분야의 실검색 답변 성공률과 출시 기준은 미검증입니다.

## 실제 아키텍처

```text
텍스트 / 브라우저 음성 → 요청 크기·길이·빈도 제한
→ 긴급 안전 안내 → 지역·짧은 후속 답변·목적 확인
→ 명확하고 질문 범위에 맞는 주요 13개 안내: 기존 공식 원문 매핑
→ 그 밖의 질문: OpenAI Responses web_search (성남 공식 도메인 제한)
→ 실제 도구 실행·출처 목록 확인 → 허용 호스트 HTTPS 원문 재확인
→ 원문 전체 맥락과 발췌 대조 → 부분 근거 / 공식 링크 / 원인별 복구 안내
→ 클라이언트 계약 검증 → 화면 및 선택적 TTS
```

새 질문은 13개 카탈로그 밖에서도 서버의 검색 제공자에 도달합니다. `PUBLIC_INFORMATION_WEB_SEARCH_ENABLED=false`인 기본 설정에서는 검색을 수행하지 못했다고 표시합니다. 이 상태를 공식자료가 없다는 뜻으로 설명하지 않습니다. API에서 새 문서를 기존 서비스 ID로 위장하지 않습니다.

기존 의도 라우터와 13개 데이터는 회귀 비교를 위해 보존했습니다. 개편 공개 API는 제한된 13개 AI 라우터를 신규 질문의 범위 판정자로 사용하지 않습니다. 모호한 교통·청년지원·도서관 질문은 선택지와 자유입력으로 확인하고, 명확하지 않은 다른 공공 질문은 공식 검색으로 연결합니다.

## 근거와 한계

공식 검색의 AI 역할은 검색 표현 선택과 관련 원문 발췌 후보 추출입니다. 서버는 검색 결과에서 확보한 URL만 확인하고 정규화된 원문 포함 여부를 대조합니다. 현재 후보에서는 자유로운 정책 요약을 표시하지 않습니다. 제목·대상·기간이 다른 문단에 있을 수 있으므로 900자 이하의 전체 본문 맥락만 발췌하며, 긴 원문은 공식 링크로 안내합니다. 이 보수적 제한은 폭넓은 답변 완수율을 저해할 수 있으며 실검색 품질 평가가 남았습니다.

런타임 허용 호스트는 `www.seongnam.go.kr`, `seongnam.go.kr`뿐입니다. 검색 제공자의 필터는 하위 도메인을 포함하지만 서버가 다시 정확한 호스트를 검사합니다. 시민게시판·후기·직원목록·첨부파일·임의 리디렉션 URL은 제외합니다. 별도 산하기관·중앙정부 도메인의 검증된 확대는 아직 없습니다.

게시일·수정일·시행기간·신청기간이 확인되지 않으면 null/미확인으로 표시합니다. HTTP 200, 검색 시각, 원문 일치만으로 현재 정책이나 개인의 자격을 보증하지 않습니다. 오늘 운영·접수 가능 여부 등 시점 민감 요청은 현재 상태를 확정하지 않습니다. 진단·개인정보 조회·민간 평가·실제 민원 접수는 제공하지 않습니다.

긴 구조화 안내는 짧은 소개를 먼저 표시하고 전체 본문을 펼쳐 보거나 따로 들을 수 있습니다. 정책 조건을 임의로 자른 요약은 만들지 않습니다. 현재 로컬 Node에서 성남시 공식 원문 HTTPS 인증서 검증이 실패했습니다. 시스템 CA 옵션으로도 해소되지 않았으며 TLS 검증을 우회하지 않았습니다. 원문 수집의 운영 호환성은 출시 전 해결할 항목입니다.

## 개인정보·보안·비용

질문과 최소 확인 문맥은 OpenAI 검색으로 전송될 수 있습니다. 전화번호·개인번호·이메일·사용자 URL을 자동 가리지만 모든 개인정보를 검출하지 못합니다. 이름·상세 주소·민감한 사정을 입력하지 마세요. 질문·음성을 앱 DB에 영구 저장하지 않습니다. 브라우저 STT/TTS와 호스팅·AI 제공자의 처리 정책은 앱 DB 미저장과 별개입니다.

원문 요청은 HTTPS·명시적 호스트만 허용하고 DNS 결과를 검사·소켓에 고정합니다. 매 리디렉션도 검증하며 사설·로컬·메타데이터 IP, 다른 포트, 과대 본문, 장시간 응답을 제한합니다. HTML은 실행하지 않습니다. 문서 캐시는 개인정보로 보이는 본문을 제외하며 최대 30건·5분이고 질문/답변 캐시는 없습니다. 캐시 확인일을 현재 시각으로 바꾸지 않습니다.

요청당 AI 1회·검색 도구 최대 1회·출력 최대 2,400토큰·검색 및 원문 확인 25초·UI 대기 30초입니다. 자동 재시도는 없습니다. 제공자가 반환하는 검색 토큰은 기본 예산을 사용하며 임의의 숫자 상한을 지원한다고 주장하지 않습니다.

기존 HTTP 제한은 프로세스당 분당 30건·동시 3건입니다. 검색은 추가로 동시 1건, 2초 간격, UTC 하루 최대 20건, 호출당 $0.15의 보수적 예상액을 예약합니다. **이것은 전역 지출 상한이 아니며 실제 비용을 강제하는 수단도 아닙니다.** Vercel 인스턴스 간 공유 제한·계정 지출한도 검증은 미완료입니다. Codex 구독과 서비스 API 과금은 별개이며 결제·자동충전·한도를 변경하지 않았습니다.

## 실행 및 검증

```bash
npm ci
npm run dev
npm run verify
npm run evaluate:offline
```

`verify`는 lint, typecheck, 서버 테스트, UI 테스트, build를 실행하며 유료 AI/검색을 끕니다. UI 각 파일은 새 서버로 격리해 서로의 분당 제한을 소모하지 않습니다. GitHub Actions에 연결했지만 원격 실행 자체는 아직 하지 않았습니다.

서버 설정 예시는 `.env.example`에 있습니다. 실제 키는 `.env.local` 또는 기존 Vercel 비밀 환경변수로만 설정하며 `NEXT_PUBLIC_`를 사용하지 않습니다.

```dotenv
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-5.6-terra
PUBLIC_INFORMATION_WEB_SEARCH_ENABLED=false
PUBLIC_INFORMATION_SEARCH_DAILY_USD=0
```

`PUBLIC_INFORMATION_AI_ENABLED`는 보존된 종전 라우터의 비교용 설정입니다. 기존 운영 모델은 바꾸지 않았습니다. 검색을 켜려면 출시 검증과 운영 예산 확인이 먼저 필요합니다. 이번 사용자 지시는 추가 유료 평가 금지이므로 켜지 않았습니다.

## 검증 기록과 출시

변경 전 서버 145/145, UI 44/44를 통과했습니다. 240개 질문은 20×8 + 대화40 + 경계40이며 60개를 보류 세트로 분리했습니다. 최초 실행 이후 보류 세트는 개발에 노출된 것으로 기록합니다. 같은 모델 계열 에이전트의 역할 분리 검토이며 시민 독립 평가가 아닙니다.

현재 검증 결과와 실패·한계는 [개편 검증 보고서](docs/voicecare-release-review.md), 고정 질문과 근거 기준은 [평가 설계](docs/voicecare-evaluation-design.md), 최초·수정 후 전체 응답은 `docs/voicecare-evaluation/`에 있습니다. 240개 계약 형식 통과와 실제 답변 성공률을 구분합니다. 종전 실모델 61/61은 역사적 결과이며 개편 출시 성공률이 아닙니다.

[처음 이용하는 사람과 실기기 확인 가이드](docs/voicecare-user-guide.md)를 참고하세요. Playwright의 모바일 크기·음성 mock은 실제 휴대폰 마이크·스피커 검증이 아닙니다.
