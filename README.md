**팀 Astra · 성남×KAIST AI 경진대회 출품작**

**과제명:** Seongnam VoiceCare AI - 일상어·음성으로 성남 공공정보의 공식 안내 연결

성남시 공식 공개정보를 기반으로, 제도명을 몰라도 음성 또는 일상적인 말로 필요한 도움을 질문하고 생활정보와 공식 출처를 찾도록 돕는 안내형 웹서비스입니다. 공식 행정 처리를 대신하지 않고 정보를 찾고 이해하는 과정을 지원합니다.

[Production 데모](https://seongnam-voicecare-ai.vercel.app/) · [GitHub 저장소](https://github.com/songeon0617/seongnam-voicecare-ai)

> 이 프로젝트는 성남시가 운영하거나 보증하는 공식 서비스가 아닙니다. 실제 신청 전에는 화면에 표시된 공식 원문에서 최신 대상·기간·절차를 다시 확인해 주세요.

## 문제 정의

공공서비스 정보는 기관과 분야별로 흩어져 있고, 정확한 제도명이나 담당 기관을 모르면 검색어를 만들기 어렵습니다. VoiceCare AI는 사용자의 목적 중심 질문을 이해해 관련 서비스를 찾고, 답변과 함께 근거가 되는 공식 페이지를 제시하여 정보 탐색의 첫 단계를 줄입니다.

## 대상 사용자

- 제도명보다 “어떤 도움이 필요한지”를 중심으로 질문하고 싶은 성남 시민
- 작은 글씨, 복잡한 메뉴, 긴 행정 문서 탐색에 부담을 느끼는 고령자와 디지털 취약계층
- 키보드 입력 대신 음성 질문이나 답변 읽어주기를 활용하고 싶은 사용자

## 핵심 기능

- 눈에 띄는 음성 질문 버튼과 홈·재질문 영역의 글자 입력란. 음성 인식(STT) 후 내용을 확인·수정하고 직접 전송
- 질문이 모호할 때 선택형 확인 질문 제공
- 공식 원문을 검토한 내부 안내 스냅샷, 분야별 공식기관 연결과 출처 관리
- 질문을 가장 먼저 보여 주는 단순한 홈과 보조 탐색인 **☰ 생활정보 찾기**
- 생활정보 메뉴 안에서 복지·이동·교통·건강·민원·생활·기타를 최대 두 단계로 탐색
- 핵심 답변 다음의 후속 질문 선택. 직전 서비스의 준비물·요금·연락처 등을 이어서 질문
- 공식 원문에서 검토한 대상·절차·서류·문의·다음 행동을 질문에 맞춰 구분
- 등록 범위 밖 질문에 대한 제한적 공식 웹 검색
- 공식 출처, 확인일, 최신성 상태를 답변과 함께 표시
- 짧은 답변 및 상세 안내 읽어주기(TTS), 재생 중지와 텍스트 대체 경로
- 지역 밖 요청, 실시간 길찾기, 개인 자격 확정 등 지원 범위 밖 질문의 명시적 제한

## 핵심 아키텍처

```text
브라우저 STT → 내용 확인·수정 후 전송 / 텍스트 입력 / 생활정보 메뉴 선택
        ↓
입력 검증 · 개인정보 패턴 완화 · 요청 제한
        ↓
지역/안전 경계 · 의도 분류 · 필요한 경우 확인 질문
        ↓
┌ 검토된 서비스 매핑 ─────────────────────────┐
└ 제한적 공식 웹 검색 → 허용 호스트/HTTPS/원문 검증 ┘
        ↓
출처가 포함된 응답 → 클라이언트 계약 검증
        ↓
화면 표시 / 선택적 브라우저 TTS
```

애플리케이션은 Next.js App Router와 React로 구성됩니다. 모델이 생성한 행정정보를 그대로 노출하지 않고, 서버가 허용된 출처와 응답 구조를 검증한 뒤 표시합니다. 공식 원문을 검토해 둔 내부 스냅샷과 생활정보 메뉴는 외부 AI 검색이 비활성화되거나 제한된 상황에서도 이용할 수 있습니다. 메뉴의 일반 탐색 요청은 무료 공식 연결로 처리하고, 상세 정책 질문은 기존 근거 확인 경로를 유지합니다.

## 공식 공공정보 기반 설계

구조화 안내는 성남시청 공개 자료를 기준으로 작성되며, 확장 검색은 코드에 명시된 성남시청·보건소·도서관사업소·성남도시개발공사 등 검토 대상 호스트로 제한됩니다. 화면의 “확인일”은 원문을 대조한 날짜이지 현재 운영을 보증하는 날짜가 아닙니다. 게시·수정일을 확인할 수 없는 자료는 최신성을 임의로 확정하지 않습니다.

## 개인정보와 안전

이름, 주민등록번호, 연락처, 상세 주소, 질환 등 개인정보나 민감정보를 입력하지 마세요. 일부 패턴을 가리지만 완전한 익명화를 보장하지 않습니다. 질문은 외부 AI 제공자에게, 음성은 브라우저의 음성 서비스에 전송될 수 있습니다. 앱은 개인의 수급 자격·의료 판단·신청 결과를 확정하거나 실제 신청을 대행하지 않습니다. 긴급 상황에서는 이 서비스 대신 112·119 등 공식 긴급 채널을 이용해야 합니다.

외부 검색에는 공유 한도와 동시 요청 제어를 적용해 API 비용과 과도한 호출을 방지합니다. 한도에 도달하거나 외부 저장소에 장애가 발생해도 구조화된 주요 안내는 계속 이용할 수 있습니다.

## 생활정보 찾기와 무료 경로

첫 화면은 **성남 생활정보를 쉽게 물어보세요 → 🎤 음성으로 질문하기 → 글자로 질문하기 → ☰ 생활정보 찾기** 순서입니다. 분야 버튼과 추천 질문을 홈에 반복해서 나열하지 않습니다. 보조 메뉴 안에서 복지 / 이동·교통 / 건강 / 민원·생활 / 기타를 선택하면 관련 항목을 보여 줍니다. 메뉴는 최대 두 단계이며 닫기·배경 닫기·Escape·키보드 포커스 순환을 지원합니다.

답변은 핵심 안내와 전화·공식 안내 버튼을 먼저 보여주고, 긴 대상·서류·절차는 **자세히 보기**로 제공합니다. 답변 하단의 큰 **🎤 다시 음성으로 질문하기**는 한 번 눌러 바로 인식을 시작합니다. **글자로 다시 질문**은 같은 위치에 입력란을 열고 초점을 옮깁니다. **처음으로**는 질문·답변·문맥을 초기화하고 홈의 음성 버튼으로 돌아갑니다.

주차장 지도, 도서관 현황, 여권 신청, 폐기물, 청년·일자리, 시설 예약, 정부24·110 등은 질문 성격에 맞는 공식기관으로 연결합니다. 기존 13개 구조화 자료는 내부 안내 스냅샷이며, 전체 서비스 범위나 홈의 핵심 서비스 목록을 뜻하지 않습니다. 새 무료 OpenAPI를 운영에 연동한 것은 없으며, 인증·갱신·호출 제한을 검토한 [무료 공공데이터 검토](docs/free-data-review.md)에 도입 보류 이유를 기록했습니다.

음성은 한 번 눌러 시작하고 말이 끝나면 확정된 문장을 보여 줍니다. **이대로 질문하기** 한 번으로 전송하며 글자로 수정하거나 다시 말할 수 있습니다. 브라우저의 확정 이벤트만으로 인식 정확성을 보장할 수 없어 자동 제출은 하지 않습니다. 30초 제한, 무음·미확정 결과·짧거나 이상한 인식·권한 거부·오류·미지원을 처리합니다. 모든 주요 기능은 음성 없이 글자로 이용할 수 있습니다.

## 로컬 실행

Node.js와 npm이 필요합니다.

```bash
git clone https://github.com/songeon0617/seongnam-voicecare-ai.git
cd seongnam-voicecare-ai
npm ci
npm run dev
```

기본 설정에서는 외부 AI와 웹 검색이 비활성화됩니다. 서버 측 연동이 필요하면 `.env.example`을 `.env.local`로 복사한 뒤 필요한 값만 설정하세요. 비밀값에는 `NEXT_PUBLIC_` 접두사를 사용하지 말고 저장소에 커밋하지 마세요.

## 검증

최신 로컬 검증 결과는 [검증 요약](docs/validation-summary.md)에 간결히 기록합니다. 전체 검사는 다음 명령으로 재현할 수 있습니다.

```bash
npm run verify
```

이번 릴리스는 홈의 중복 탐색을 제거하고 음성 우선 질문과 답변 아래 재질문을 정리합니다. 실제 검사 종류·통과 수치·장치 검증 한계는 [검증 요약](docs/validation-summary.md)에 기록합니다. 공식 원문 확인 기록은 2026-09-09 기준이며, 날짜가 없는 정책의 최신성을 확정하지 않습니다.

`verify`는 lint, typecheck, 서버 테스트, Chromium 기반 UI 테스트, production build를 순서대로 실행합니다. 자동 테스트의 음성 API는 mock을 사용하므로 실제 기기의 마이크 인식률, 한국어 음성 품질, 스크린리더 사용성을 검증했다는 의미는 아닙니다. 실제 사용자 대상 사용성 평가는 후속 과제입니다.

## 고지

VoiceCare AI는 경진대회용 프로토타입이며 성남시 공식 서비스가 아닙니다. 검토된 내부 안내, 분야별 공식기관 연결과 제한적 공식 검색을 지원하지만 모든 공공 질문에 답하거나 정확도 100%를 보장하지 않습니다. 공식 행정 처리, 개인정보 조회, 진단, 수급 자격 확정, 실제 신청 대행, 정확한 출발지·목적지 경로와 환승·도착 시각 계산은 지원하지 않습니다. 중요한 결정과 실제 신청은 반드시 연결된 공식 기관의 최신 안내를 기준으로 하세요.
