# Seongnam VoiceCare AI

성남시 공식 공공정보를 말이나 글로 질문하고, 근거 문서와 함께 확인하는 접근성 중심 경진대회 프로토타입입니다.

## 문제 정의

성남시의 복지·교통·건강·행정 정보는 여러 페이지에 나뉘어 있고 제도명이 익숙하지 않으면 필요한 안내를 찾기 어렵습니다. 특히 작은 글씨, 복잡한 메뉴, 검색어 선택에 어려움을 겪는 시민에게는 정보가 공개되어 있어도 실제 접근 장벽이 남습니다.

## 주요 대상 사용자

- 성남시 고령자
- 시각장애인
- 디지털 기기와 온라인 검색에 익숙하지 않은 디지털 취약계층
- 복지·교통·건강·행정 서비스의 정확한 제도명을 모르는 시민과 보호자

## 해결 방식

사용자는 텍스트 또는 음성으로 질문합니다. 서버는 먼저 기존 키워드 검색을 사용하고, 질문이 불명확할 때만 AI가 서비스 의도를 분류하도록 보조합니다. 최종 사실 답변은 AI가 작성하거나 요약하지 않습니다. 등록된 성남시 공식 문서 중 검증된 서비스 ID를 결정론적으로 조회해 제목, 원문, 대상, 출처, 확인 상태를 매핑합니다.

```text
텍스트·브라우저 음성 질문
  → 키워드 검색
  → 필요할 때만 AI 의도 분류·라우팅 보조
  → DIRECT / CLARIFY / UNSUPPORTED
  → 등록된 공식 문서의 결정론적 답변 매핑
  → 답변·출처·확인 상태 표시 및 선택적 답변 듣기
```

## 주요 기능

- 텍스트 질문과 예시 질문
- 브라우저 음성 인식 기반 한국어 질문
- 13개 공식 문서를 대상으로 한 키워드 검색과 서비스 의도 라우팅
- 명확한 질문은 공식 문서로 직접 연결하고, 모호한 질문은 고정 확인 질문 제공
- 등록 범위 밖의 요청은 사실·출처 없이 미지원으로 안내
- 공식 문서 원문 기반 답변, 출처 URL, 확인일, 문서 상태 표시
- 사용자가 선택한 실제 답변의 브라우저 음성 읽기와 중지
- 긴급 안전 표현에 대한 고정 안내 및 직접 연락 링크

## 실제 구현 범위

현재 `PublicInformationDocument`는 13개입니다.

1. 특별교통수단 운영
2. 장애인 택시바우처
3. 노인맞춤돌봄서비스
4. 분당노인종합복지관
5. AI·IoT 기반 어르신 건강관리
6. 장애인 보조기구·보장구 지원
7. 발달장애인 지원
8. 장애인 보건·의료서비스 지원
9. 중원구보건소 치매안심센터
10. 맞춤형 방문건강관리
11. 무인민원발급기 이용 안내
12. 긴급복지지원 사업
13. 장애인 버스요금 지원

이 범위는 성남시 전체 정책을 포괄하지 않습니다. 현재 검색은 로컬 TypeScript 데이터와 키워드 기준선을 사용합니다. RAG, Vector DB, embedding은 구현하지 않았습니다.

## 데모 / 사용 방법

1. 제출서에 기재된 Vercel Production 주소 또는 로컬 서버에 접속합니다.
2. 마이크 버튼을 눌러 말하거나 입력란에 질문을 작성합니다.
3. 확인 질문이 나오면 필요한 도움을 선택하거나 더 구체적으로 입력합니다.
4. 답변의 공식 출처와 확인 상태를 함께 확인합니다.
5. 실제 답변이 있을 때만 표시되는 **답변 듣기**로 본문을 들을 수 있습니다.

데모 질문 예시:

- `휠체어 타는데 부를 수 있는 차 있어요?`
- `혼자 사는 어머니 안부를 챙겨주는 도움 있나요?`
- `등본을 기계로 뽑으려면 어디서 확인해요?`

## 데이터 출처

데이터는 성남시청 공식 웹사이트(`seongnam.go.kr`)에서 확인한 공공정보만 등록합니다. 원문, 공식 URL, 기관명, 확인일, 문서 상태를 구조화해 관리하며 활성 상태의 공식 출처만 검색과 답변 매핑에 사용합니다. 세부 문서와 URL은 [`src/data/public-data/documents.ts`](src/data/public-data/documents.ts), 출처 허용 목록은 [`src/data/public-data/sources.ts`](src/data/public-data/sources.ts)에서 확인할 수 있습니다.

## AI 사용 범위

AI의 실제 역할은 **사용자 질문의 서비스 의도 분류와 라우팅 보조**입니다. 질문이 키워드만으로 명확하지 않을 때 질문 내용 일부, 선택적인 직전 확인 문맥, 13개 서비스의 짧은 카탈로그를 OpenAI Responses API에 전달할 수 있습니다.

AI 출력은 `DIRECT`, `CLARIFY`, `UNSUPPORTED` 경로와 허용된 서비스 ID·의도·확인 질문 ID로 제한됩니다. 서버가 스키마와 허용 ID를 다시 검증하며, 자유 문장이나 정책 사실을 답변에 병합하지 않습니다. 최종 사실 답변은 선택된 공식 문서를 서버 코드가 결정론적으로 매핑합니다.

## 안전장치

- AI가 정책 사실, 자격, 연락처, 서류, 장소, 비용 또는 진단을 생성하지 않음
- 잘못된 AI 출력, 제공자 오류, 시간 초과 시 키워드 답변 또는 고정 확인 질문으로 복귀
- 등록 문서 밖의 요청과 가까운 시설 추정 등 확인할 수 없는 요청을 보수적으로 제한
- 답변 본문을 HTML로 실행하지 않고 HTTPS 출처만 허용
- 긴급 표현은 일반 공공정보 답변과 분리된 고정 안전 안내로 처리
- 질문 길이, 요청 본문 크기, 처리 시간, 단일 프로세스 요청 빈도를 제한
- 질문 내용 일부가 AI 분류에 사용될 수 있음을 알리고 민감한 개인정보 입력을 피하도록 UI에서 안내

## 검증 결과

| 검증 | 결과 |
| --- | ---: |
| Server tests | 124/124 PASS |
| UI tests | 43/43 PASS |
| 실제 공개 API E2E 질문셋 | 54/54 PASS |
| ESLint / TypeScript / Production build | PASS |

54/54는 2026-09-06에 고정된 54개 질문을 공개 API 경로로 각 1회 실행한 결과입니다. 해당 질문셋의 기대 route, 서비스 선택, 확인 질문, 공식 문서 기반 답변 무결성을 모두 만족했다는 뜻이며, 임의의 실제 질문에 대한 일반적 정확도 100%를 의미하지 않습니다. 상세 기준과 전체 사례는 [`docs/public-information-e2e-validation.md`](docs/public-information-e2e-validation.md)에 있습니다.

자동 테스트는 실제 OpenAI를 호출하지 않습니다. 실제 모델 평가는 별도 명령과 운영 키로 수행한 기록을 자동 회귀 결과와 구분합니다.

## 기술 스택

- Next.js 16.3.4 App Router, React 19.2.8, TypeScript 5
- Next.js Route Handler 기반 서버 API
- OpenAI Responses API + Structured Outputs(선택적 의도 분류)
- 브라우저 Web Speech API의 `SpeechRecognition` / `webkitSpeechRecognition`, `speechSynthesis`
- Node test runner + `tsx`, Playwright, ESLint
- Vercel Production

STT와 TTS는 별도 AI 음성 서버가 아니라 브라우저 Web Speech API를 사용합니다. 지원 여부, 음성 처리 방식, 한국어 음성 품질은 브라우저와 운영체제에 따라 달라질 수 있습니다.

## 로컬 실행법

Node.js와 npm이 준비된 환경에서 실행합니다.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. AI 라우팅은 기본 비활성입니다. 사용하려면 `.env.example`을 참고해 서버 전용 `.env.local`에 아래 값을 설정합니다. `NEXT_PUBLIC_` 접두사는 사용하지 않습니다.

```dotenv
PUBLIC_INFORMATION_AI_ENABLED=true
OPENAI_API_KEY=...
OPENAI_MODEL=...
```

검증 명령:

```bash
npm run test:server
npm run test:ui
npm run lint
npm run typecheck
npm run build
```

Playwright 브라우저가 없다면 최초 1회 `npx playwright install chromium`이 필요합니다.

## 한계

- 등록된 13개 문서 밖의 성남시 정책과 실시간 변경 사항은 답할 수 없습니다.
- 공식 원문을 AI가 쉬운 말로 재작성하거나 개인 상황에 맞게 판단하지 않습니다.
- RAG, Vector DB, embedding, 실시간 웹 검색을 사용하지 않습니다.
- 문서에 없는 전화번호·서류·금액·가까운 시설을 추정하지 않습니다.
- AI 라우팅은 확률적이므로 고정 평가셋 밖의 모든 표현을 보장하지 않습니다.
- 브라우저 음성 기능은 기기·브라우저 권한과 지원 범위에 의존합니다.
- 의료·법률·복지 수급 자격을 확정하는 서비스가 아니며 최종 확인은 표시된 공식 출처와 담당 기관에서 해야 합니다.
