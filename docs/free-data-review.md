버스의 [공식 API 매뉴얼](https://gbis.go.kr/gbis2014/publicService.action?cmd=mBusArrivalStation)은 serviceKey, stationId 등 요청 조건과 JSON/XML 응답을 설명한다. 인증키 신청이나 계정 생성은 수행하지 않았다. 향후 키를 발급받으면 성남 정류소 실응답, 시간표시, 호출 제한, 캐시 만료, 타임아웃·장애 전환을 검증한 뒤 도입해야 한다.

현재 제품은 질문→기존 안전·지역·확인 질문 처리→공식 원문을 검토해 둔 내부 안내 스냅샷 또는 정확한 무료 공식 연결→필요한 경우 기존 제한형 공식 검색 순서로 동작한다. 상세 정책 질문을 단순 홈페이지 링크로 무조건 바꾸지 않는다. 기존 13개 스냅샷은 내부 자료이며 홈의 서비스 목록이나 전체 지원 범위를 뜻하지 않는다.

첫 화면은 음성 질문·글자 대안·보조 메뉴로 구성한다. 분야를 반복 노출하지 않으며, 생활정보 찾기 안의 복지·이동·교통·건강·민원·생활·기타 항목은 실제 내부 안내 또는 검토된 기관 경로가 있을 때만 제공한다. 연결 경로는 서버의 원문 수집 허용 호스트와 별도로 관리하며, 정부24·110 링크를 추가했다고 외부 검색의 허용 호스트를 확대하지 않았다. 서버 검색에 실패했을 때도 해당 주제의 공식기관을 제시한다. 전화·민원 신청은 사용자가 직접 실행하며, 자동 신고·개인 자격 확정·예약 대행을 하지 않는다.

공식기관 경로의 확인일은 페이지를 열어 연결 용도를 확인한 날짜다. 정책 최신성·접수 가능 여부·개인별 혜택을 보장하지 않는다. 외부 페이지가 일시 중단되면 알려진 담당 전화가 있는 경우 전화로 확인할 수 있고, 없는 경우 해당 기관의 홈페이지에서 다시 찾아야 한다.
