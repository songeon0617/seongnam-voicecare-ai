# Seongnam VoiceCare AI · Astra

제도명을 몰라도 필요한 도움을 글이나 음성으로 질문하고, 성남의 공식 안내와 출처에 도달하도록 돕는 경진대회 프로토타입입니다. 어르신·시각장애인·디지털 취약계층의 정보 탐색 부담을 줄이는 것을 목표로 합니다. **성남시가 운영하는 공식 서비스가 아닙니다.**

## 실제 기능

한국어 텍스트·브라우저 음성 질문, 필요한 경우 확인 질문, 공식 자료 안내, 출처·확인일·최신성 표시, 답변 듣기·중지·상세 안내 듣기를 제공합니다. 마이크나 한국어 읽기를 지원하지 않는 환경에서는 텍스트를 사용합니다.

검토된 구조화 공식 문서는 **13개**, 고유 근거 URL은 **25개**입니다. 어르신 돌봄, 장애인복지, 교통약자 이동, 방문건강관리, 긴급복지, 무인민원발급기 등이 포함됩니다. 명확한 등록 서비스 질문은 AI 비용 없이 처리합니다. 나머지 질문은 공식 웹 검색과 HTTPS 원문 대조를 시도합니다. 공식 검색·Redis 공유 제한은 Production에 배포되어 있습니다.

## 동작 구조

```text
텍스트 / 브라우저 STT
→ 요청 크기·시간·빈도 제한
→ 긴급 안전 안내 / 지역·지원 범위 확인 / 모호한 목적 되묻기
→ 명확한 등록 서비스: 검토된 공식 자료 매핑
→ 그 밖의 질문: OpenAI Responses web_search
→ 허용된 공식 호스트·검색 출처 검증 → HTTPS 원문 대조
→ 원문 근거 / 공식 링크 / 실패 원인과 지원 제한
→ 클라이언트 응답 검증 → 화면 및 선택적 브라우저 TTS
```

AI는 검색 표현과 원문 발췌 후보를 찾습니다. 서버는 출처의 허용 여부와 원문 일치·질문 관련성을 검사하며, 모델이 만든 행정정보를 그대로 노출하지 않습니다. 긴 안내는 전체 조건을 보존합니다. HTML을 실행하거나 실시간 교통 API를 호출하지 않습니다.

## 공식성과 최신성의 구분

허용 호스트 11개는 성남시청, 보건소, 도서관사업소, 성남도시개발공사, 청년지원센터, 일자리센터, 문화재단 등의 검토된 사이트입니다. 목록은 `src/lib/search/official-source-policy.ts`에 있습니다. 임의 하위 도메인을 신뢰하지 않습니다.

게시·수정일을 확인하지 못한 구조화 자료 12개는 `unknown`을 유지합니다. 나머지 1개는 검토 기준의 `current`입니다. **확인일은 원문을 대조한 날짜이며 정책 시행일이나 오늘의 운영 보장이 아닙니다.** 웹 검색 근거도 최신성 미확인을 명시합니다. 원문이 공식 자료라도 오래되거나 서로 상충할 수 있습니다.

## 명확히 제한하는 질문

- 출발지→목적지의 정확한 경로·환승·도착 시각: 미지원. 성남시 버스 안내를 통한 공식 교통정보 확인으로 연결합니다.
- 음식물쓰레기: 동적 페이지의 자동 본문 대조는 미지원. 브라우저에서 확인한 공식 상세페이지로 연결합니다.
- 온라인 전입신고: 현재 수집 자료로 상세 조건·인증 절차를 확정하지 않습니다. 정부24에서 직접 확인하도록 안내합니다.
- 금연상담 무료 여부: 보조제 무료 지원만으로 상담 비용을 확정하지 않습니다.
- 개인의 자격 확정, 진단, 개인정보 조회, 실제 신청·접수, 다른 지역 행정 안내는 제공하지 않습니다.

일반 버스와 민원 시작 안내는 공식 상세페이지 탐색을 보완했습니다. 상세 답변의 성공 여부와 지원 제한의 정상 동작은 따로 평가합니다. 모든 공공 질문을 답하는 서비스나 정확도 100%로 소개하지 않습니다.

## 개인정보·보안·비용

질문과 직전 확인 문맥은 OpenAI로, 음성은 브라우저의 음성 서비스로 전송될 수 있습니다. 번호·이메일·URL 자동 가림은 완전하지 않습니다. 이름·주민번호·연락처·민감한 사정을 입력하지 마세요. 앱은 질문·음성을 DB에 영구 저장하지 않습니다. 외부 제공자의 처리·보관 정책과는 별개입니다.

API 키와 Redis 토큰은 서버 환경변수에서만 읽습니다. 실제 `.env.local`은 Git에서 제외됩니다. HTTPS·정확한 호스트·DNS/IP·리디렉션을 검사하고 인증서 검증을 유지합니다. 제한된 문서·검색 캐시를 사용하며 캐시 대조 시각을 현재로 바꾸지 않습니다.

Production은 Redis 원자 예약으로 **UTC 하루 공유 최대 20회(한국시간 오전 9시 갱신)**, 동시 검색 1개, 최소 간격 2초를 적용합니다. Redis 누락·장애·잘못된 응답에서는 유료 검색을 차단합니다. 설정을 추가하거나 카운터를 초기화할 필요가 없습니다. 한도 소진 시 등록된 13개 안내는 계속 사용할 수 있습니다.

호출당 $0.15를 예상액으로 예약하며 최대 예약 예산은 하루 $3입니다. **이 예약액은 실제 API 청구액의 강제 상한이 아닙니다.** HTTP 요청 제한은 인스턴스당 30/분·동시 3개이고, 검색의 하루 제한은 인스턴스 간 공유합니다. 요청당 모델 1회·검색 1회·원문 fetch 최대 16회, 서버 검색 25초·UI 30초 제한과 자동 재시도 금지를 유지합니다.

## 실행과 검증

```bash
npm ci
npm run dev
npm run verify
```

`verify`는 lint → typecheck → 서버 테스트 → UI 테스트 → build를 실행하며 유료 AI/검색을 끕니다. GitHub Actions의 Offline regression도 같은 검사를 수행합니다. Production 운영 설정과 로컬 기본값은 다릅니다. 비밀이 없는 설정 예시는 `.env.example`을 참고하세요.

최종 결과·재실행 여부·새 모델 호출 수는 [최종 보고서](docs/submission-final-review.md)에 기록합니다. 과거 `docs/final-*`, `docs/voicecare-*-20260907.md`와 평가 JSON은 당시 증거이며 최신 출시 상태를 대신하지 않습니다. 고정 테스트 통과는 외부 질문 전체의 정확도나 실제 시민 사용성 검증을 의미하지 않습니다.

실제 마이크·스피커·스크린리더와 제출 기기에서의 확인은 자동 음성 mock·모바일 viewport 검사와 별개입니다. 사용자 편익의 실측 결과나 접근성 인증은 아직 없습니다. 새로운 DB·계정·지도 API·벡터 DB를 추가하지 않습니다.

제출 원본 `docs/submission-2026/`은 개인정보·서명 보호를 위해 Git에서 제외됩니다. 해당 파일의 제출 전 수정 항목은 최종 보고서에서 확인하세요.
