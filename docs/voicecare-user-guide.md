# Astra VoiceCare 이용 및 실기기 확인

기본 지역은 성남시입니다. 성남시가 직접 운영하는 서비스가 아닙니다. 아래 기능은 [Production](https://seongnam-voicecare-ai.vercel.app/)에서 이용합니다. 자동 검사 범위와 한계는 [검증 요약](validation-summary.md)을 참고하세요.

1. PC에서는 큰 입력란에 필요한 일을 적고 ‘질문하기’를 누릅니다. 제도명을 몰라도 됩니다.
2. ‘이동수단 알려줘’에는 일반 버스·지하철, 차량 지원, 비용 도움 선택이 나옵니다. 선택을 누르거나 ‘1번’, ‘일반 버스요’처럼 답합니다.
3. 목적을 모르겠으면 ‘잘 모르겠어요’를 누릅니다. 새 주제는 ‘새 질문하기’로 시작할 수 있습니다.
4. 공식 원문·출처·확인일을 함께 읽습니다. ‘미확인’은 현재 운영·신청 자격이 확정되지 않았다는 뜻입니다.
5. 웹 검색이 꺼져 있거나 한도가 끝나면 그 사유가 나옵니다. ‘다시 시도’ 또는 성남시 공식 홈페이지를 이용합니다. 이런 상태는 답변 성공이 아닙니다.

휴대폰은 글자 입력을 기본으로도 이용할 수 있습니다. ‘말로 질문하기’를 누르면 지원되는 브라우저에서 마이크 권한을 요청합니다. 인식된 질문이 자동 전송되므로 결과를 입력란에서 확인하고 잘못 인식되면 수정해 다시 보냅니다. 다시 누르면 인식을 취소합니다. 화면을 다른 앱으로 전환하면 진행 중 음성 입력을 취소합니다. 브라우저 마이크가 없다면 휴대폰 키보드의 음성 입력을 이용할 수 있습니다.

‘답변 듣기’는 화면의 짧은 안내를 읽으며 자동 재생하지 않습니다. 긴 정책 본문은 ‘상세 안내 펼치기’에서 확인하고 ‘상세 안내 전체 듣기’로 따로 들을 수 있습니다. 중지 버튼, 새 질문, 입력 수정은 이전 읽기를 취소합니다. TTS가 모든 출처·확인 상태를 대신 설명하지 않으므로 화면의 공식 근거도 확인하세요.

이름, 주민번호, 전화번호, 상세 주소, 개인 질환 정보를 넣지 마세요. 자동 가림은 완전하지 않습니다. 질문은 외부 AI 검색으로, 음성은 브라우저 제공자의 음성 서비스로 처리될 수 있습니다.

## 실제 기기 체크표 — 아직 미검증

| 기기/브라우저 | 확인할 동작 | 현재 상태 |
| --- | --- | --- |
| iPhone Safari | HTTPS에서 마이크 버튼·권한 허용·한국어 인식·전사 수정 | 미검증 |
| Android Chrome | 동일 절차, 휴대폰 키보드 음성 입력 대체 | 미검증 |
| 양쪽 기기 | 권한 거부 후 텍스트 질문, 무음 후 재시도, 백그라운드 전환 취소 | 미검증 |
| 양쪽 기기 | 답변 듣기·중지·새 답변 전환, 실제 한국어 발음과 볼륨 | 미검증 |
| 실제 스크린리더 | 입력 라벨·확인 선택·상태·출처·미확인 상태 탐색 | 미검증 |
| 휴대폰 키보드 | 입력란·전송 버튼 가림, 회전, OS 글자 확대 | 미검증 |

각 기기에서 ‘이동수단 알려줘’ → 차량 지원 선택, ‘특별교통수단 신청 방법’, ‘혼자 사는 어머니 안부를 챙겨주는 도움 있나요?’를 시도하고 표시 내용과 실패를 그대로 기록합니다. 확장 검색은 운영 한도와 외부 사이트 상태에 따라 실패할 수 있습니다. 긴급 안전 문구 시험은 화면만 확인하며 전화 링크를 실제로 누르지 않습니다.

데스크톱 Chromium에서 여러 모바일·데스크톱 폭, CSS 글자 200%와 키보드 focus를 자동 검사합니다. 이것은 실기기 접근성 인증이나 실제 음성 시험이 아닙니다.
