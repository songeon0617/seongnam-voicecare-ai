`node scripts/verify-voicecare.mjs`는 lint→typecheck→서버→UI→build를 실행합니다. `node node_modules/@playwright/test/cli.js test competition-flow.spec.ts --browser=all`로 브라우저별 동선을 확인합니다. HTTP 검사는 빌드 후 `node scripts/check-voicecare-legacy-release.mjs`로 실행하며, 결과 폴더는 `VOICECARE_RESULT_DIRECTORY`로 지정합니다.

HTTP 검사의 예전 ‘원문 전체와 답변이 같아야 함’ 조건은 질문별 구조화 응답 계약으로 갱신했습니다. 이 검사는 사실 정확도 점수가 아닙니다. 답변 품질 시나리오는 실제 공식 문서의 조건·금액·연락처를 기대값으로 별도 확인합니다. 수치들은 검사 범위가 겹치므로 합산한 고유 사례 수로 발표하지 않습니다.

직접 본 데스크톱 브라우저의 390px 화면에서 중복 입력 버튼으로 분야 선택이 밀리는 문제를 수정했습니다. 예시 클릭 후 답변에 초점이 이동하고, 핵심 안내 다음에 후속 질문을 배치했습니다. 무인민원발급기 ‘이용 안내와 설치 장소’에서 이용 절차가 빠지는 결함도 모바일 동선 검사에서 찾아 수정했습니다.
